## 🚀 How to Run Locally

Because this project uses pure HTML5, CSS3, and JavaScript with **zero build steps or external dependencies**, you can run it immediately on any machine:

### Option A: Direct File Open
1. Double-click `index.html` in your file explorer.
2. It will open directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option B: Local HTTP Server (Recommended)
Running through a local web server ensures PDF previews and asset paths behave exactly like production:

Using **Python**:
```bash
# Navigate to the project directory
cd MyPortfolio

# Launch local server on port 8000
python -m http.server 8000
```
Then open your browser and visit: `http://localhost:8000`

1. Save your certificate (PDF, PNG, or JPEG) inside `assets/certificates/` (e.g. `assets/certificates/ibm_skillsbuild_social_media.pdf`).
2. In `index.html` under `#certifications`, update the link:
   ```html

     View Certificate

   ```

## 🌐 How to Publish for Free on GitHub Pages

You can host your personal website live on the web with free hosting:

1. **Initialize Git Repository** (if not already done):
   ```bash
   cd MyPortfolio
   git init
   git add .
   git commit -m "Complete academic profile website for Suryakrishna K V"
   ```

2. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name your repository (for example, `MyPortfolio` or `suryakrishnakv.github.io`).
   - Leave it **Public**.

3. **Push Your Code**:
   ```bash
   git remote add origin https://github.com/Suryakrishnakv/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - On GitHub, navigate to your repository **Settings** tab.
   - On the left sidebar, click **Pages**.
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
   - Within 1–2 minutes, GitHub Pages will deploy your site at:
     `https://suryakrishnakv.github.io/<repo-name>/`
