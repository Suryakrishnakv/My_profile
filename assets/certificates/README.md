# Certificates Directory
Place your certificate files (PDFs, PNGs, or JPEGs) in this folder.

Example filenames:
- ibm_skillsbuild_social_media.pdf
- python_analytics_cert.pdf

In `index.html`, update the link in the Certifications section:
`<a href="assets/certificates/your_certificate_name.pdf" target="_blank">View Certificate</a>`
