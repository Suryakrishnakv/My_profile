# Documents Directory
Place your official resume / curriculum vitae (PDF) in this folder.

Standard expected filename:
- `Suryakrishna_KV_Resume.pdf`

The "Download Resume" button on your portfolio website is configured to link directly to:
`assets/documents/Suryakrishna_KV_Resume.pdf`

Whenever you update your resume, simply overwrite `Suryakrishna_KV_Resume.pdf` in this folder, and your portfolio download button will automatically serve the updated version!
